INFINITY ATLAS - WEBSITE STARTER

This is a static starter website designed around an Culture & literature blog.
You can rename the site, edit the text, add your own posts, and publish it using a hosting provider.

IMPORTANT:
- This is a website starter, not a live website or registered domain.
- The sample articles are starter content. Add original, useful content before applying to AdSense.
- Replace the placeholder email address on contact.html.
- Customize the privacy policy to match your actual website, analytics and advertising tools.
- Do not publish copyrighted poetry or images without permission or a valid legal basis.
- AdSense approval is not guaranteed. Google reviews websites and traffic quality.

HOW TO PREVIEW:
Open index.html in a web browser.

HOW TO ADD A POST:
1. Copy one of the HTML files in the posts folder.
2. Give it a new filename.
3. Replace the title and article text.
4. Add a new article card to index.html linking to the new post.
5. Upload the updated website files to your host.

PUBLISHING:
You can publish the files using a static host such as Cloudflare Pages. Connect a custom domain you register separately.
This starter does not include a secure online admin dashboard. For posting from your phone without editing files, a CMS or WordPress-based setup is more convenient.

SITE NAME:
Currently "Infinity Atlas" - change this to your preferred name throughout the files.
